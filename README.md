# podkop-engine для podkop — установка одной командой

Ставит на роутер [podkop-engine](https://github.com/FiyeroT/podkop-engine) — улучшенную сборку sing-box для podkop — и обновляет podkop до свежей версии. Настройки и ключи podkop не меняются.

**Что это даёт:**
- в podkop можно добавлять ключи с транспортом **XHTTP**, а они часто работают там, где обычный Reality режется;
- если DNS через VPN упал, роутер сам переключается на DNS провайдера, и интернет не пропадает целиком;
- автовыбор сервера быстрее уходит с упавшего сервера, а перед переключением проверяет новый скачиванием;
- **защита:** если sing-box начнёт падать, podkop выключится сам, и дома останется обычный интернет без VPN.

**Подходит для:** Xiaomi AX3000T на OpenWrt 24.10 с уже установленным и настроенным podkop.

## Установка

1. Подключись к роутеру. На Windows открой PowerShell, на Mac или Linux — Терминал:
   ```
   ssh root@192.168.1.1
   ```
2. Скачай скрипт:
   ```
   wget -O /root/pe.sh https://raw.githubusercontent.com/markiitwo/podkop-engine-installer/main/install.sh
   ```
3. Сначала проверь, подходит ли роутер (ничего не меняется):
   ```
   sh /root/pe.sh check
   ```
4. Установи:
   ```
   sh /root/pe.sh
   ```
   Скрипт покажет план и спросит подтверждение. Интернет пропадёт примерно на 1–2 минуты.

Если SSH оборвётся во время установки, ничего страшного: установка закончится сама. Через минуту подключись снова и запусти `sh /root/pe.sh report`, чтобы посмотреть, чем всё закончилось.

## Если что-то не так

| Команда | Что делает |
|---|---|
| `sh /root/pe.sh report` | Собирает отчёт о роутере для помощи. Ключи, пароли и UUID в нём заменены на `***`. Скопируй вывод целиком и пришли тому, кто помогает. |
| `sh /root/pe.sh rollback` | Возвращает обычный sing-box. podkop остаётся на новой версии, с обычным sing-box он тоже работает. |
| `sh /root/pe.sh check` | Только проверка, ничего не меняет. |

Если проверка после установки не прошла, скрипт **сам вернёт всё как было**.

Что лежит на роутере:
- `/root/podkop-engine-backup/` — архив настроек до установки и пакет старого sing-box для отката;
- `/root/podkop-engine-backup/install.log` — подробный лог установки.

## Что именно делает скрипт

1. **Проверяет роутер:** модель, версию OpenWrt, podkop, свободную память и флеш, интернет, работает ли VPN прямо сейчас.
2. **Пока интернет и VPN работают, скачивает всё нужное:**
   - podkop-engine и podkop — конкретных проверенных версий, сверяя контрольные суммы. Скачивает через podkop, поэтому замедление GitHub провайдером не мешает;
   - недостающие зависимости;
   - копию нынешнего sing-box для отката.
3. **Сохраняет настройки** в архив.
4. **Устанавливает:** останавливает podkop, ставит podkop-engine вместо sing-box, обновляет podkop и интерфейс в LuCI.
5. **Проверяет:**
   - запустился ли sing-box;
   - отвечает ли DNS podkop и обычный DNS;
   - работает ли VPN, если он работал до установки.

   Если хоть что-то не прошло — откат.

Версии в скрипте зафиксированы: podkop-engine 1.14.2-r12 и podkop 0.7.23. Новые версии добавляются в скрипт после проверки.
